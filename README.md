말씀 보석 100은 [TK-KOREA/100-verses](https://github.com/TK-KOREA/100-verses)로 옮겼다(2026-10-12).
이 저장소는 옛 주소 https://tk-korea.github.io/verse-100-steps/ 로 들어온 사람과 설치된 앱을 새 주소로 넘겨준다. 지우지 않는다.

- `index.html`, `404.html`: 새 주소로 넘긴다. `#/verse/30` 같은 구절 위치는 그대로.
- `sw.js`: 옛 주소에 설치된 앱의 오프라인 저장을 끝낸다. 진도는 같은 출처(tk-korea.github.io)에 있어 그대로 남는다.
